Favicon Guide

What is a favicon?

A favicon is the small website identity icon shown in browser tabs, bookmarks, search results and app shortcuts.

Why favicons matter

Favicons improve recognition, trust, installability and polish across browsers, mobile devices and PWAs.

Recommended favicon sizes

Use 16, 32, 48, 64, 96, 128, 180, 192, 256, 384 and 512 pixel PNG icons plus a multi-resolution ICO.

How to add favicon to a website

Upload the generated files to your site and paste the HTML snippet inside the document head.

Cloudflare Pages favicon guide

Place generated icons in your static output folder, usually `public/favicons` or the generated `dist/favicons` directory before deployment.

Jekyll favicon guide

Copy icons into your Jekyll site root or assets folder and include `jekyll-snippet.html` from your `_includes/head.html` file.

FAQ

Are images uploaded to a server?

No. Processing happens in your browser using canvas and static JavaScript.

Does this work offline?

Yes. After the first successful load, the service worker caches the static app shell.

Can I deploy this on Cloudflare Pages?

Yes. It is fully static. Use `npm run build` optionally and deploy `dist`.

Which formats are supported?

PNG, JPG, JPEG, WEBP and SVG are supported when the current browser can decode them.
